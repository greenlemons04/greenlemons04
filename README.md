### Project Factio — Unreal Engine Horror Game

**Unreal Engine 5 • C++ • Blueprints • AI Systems**

Project Factio is a first-person survival-horror game I am developing independently in Unreal Engine 5.

The project focuses on stealth, exploration, environmental interaction, and enemy AI rather than combat.

Current systems include:

- First-person movement and interaction
- C++ / Blueprint interaction architecture
- Key and inventory systems
- AI perception using sight and hearing
- Patrol, chase, search, and investigation behavior
- Environmental distraction systems
- Checkpoints and player respawning
- Modular interactable objects

The full development repository is private, while the public repository contains selected technical documentation and project information.
